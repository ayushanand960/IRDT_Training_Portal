# Project Backup – IRDT Training Management Portal

This is a **formal backup** for record-keeping. It includes a built frontend, a database snapshot, and minimal backend references (models/admin).  
It is **not deployable as-is**. For deployment, contact the development team.

## Contents
- `frontend_dist/` – Production build (static files)
- `backend_partial/`  
  - `database/db.sqlite3` – Snapshot
  - `apps/models_backup/` & `apps/admin_backup/` – Structure only
  - `settings_backup/settings_template.py` – Non-secret template
  - `requirements.txt` – Sanitized (not pinned)
- `docs/` – Documentation
